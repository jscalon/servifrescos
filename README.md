Este proyecto es una aplicación web desarrollada con React y TypeScript, utilizando Vite como herramienta de construcción. Actualmente, cuenta con una página de login que incluye componentes para el encabezado, contenido, tarjetas y pie de página. La aplicación está diseñada para Servifresco y incluye activos relacionados con las marcas Proagro y Protinal, sugiriendo un enfoque en la gestión de productos o catálogos para estas empresas.
