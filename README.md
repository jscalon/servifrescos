# ServiFresco

Este proyecto es una aplicación web desarrollada con **React** y **TypeScript,** utilizando Vite como herramienta de construcción.

---

Actualmente, cuenta con una página de login que incluye componentes para el encabezado, contenido, tarjetas y pie de página. La aplicación está diseñada para las tiendas Servifresco de la empresa Protinal Proagro, con enfoque en la gestión de productos o catálogos.
